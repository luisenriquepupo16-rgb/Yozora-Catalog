# Yozora Store

## 📱 Descripción

Yozora Store es un catálogo de aplicaciones desarrolladas por Yozora.  
Una tienda virtual donde puedes descargar todas mis aplicaciones en un solo lugar, con soporte offline y experiencia mejorada.

---

## ✨ Características

- ✅ Catálogo de aplicaciones por categorías
- ✅ Descarga directa de APKs
- ✅ Funciona sin internet (modo offline con caché)
- ✅ Progreso de carga en tiempo real
- ✅ Página de error personalizada
- ✅ Actualizaciones automáticas desde GitHub
- ✅ Pantalla de carga con icono de gato

---

## 🛠️ Tecnologías

- Kotlin + Android SDK
- WebView con caché offline (LOAD_CACHE_ELSE_NETWORK)
- GitHub Pages como backend
- SwipeRefreshLayout para recarga manual
